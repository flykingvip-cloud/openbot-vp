## 6. 方案第 8 节最终验收矩阵（S5 实跑，S1–S4 可先做可重复的注入骨架）

| 场景 | 必须观察到的事实 |
| --- | --- |
| 普通问答 | 必要时一次交互推理；零业务执行、零任务板、零质量审阅模型 |
| 当前回合小任务 | 正常准入、真实动作、可见结果；无持久看板和后续唤醒 |
| 长任务中普通问答 | 回应不等待 A 完成，不改 A 的状态 |
| 长任务修订 | 原目标版本更新，动作前限制生效；回执区分收到／生效／在途影响 |
| 暂停／取消与恢复竞争 | 旧动作／回调不能继续推进，事实不丢，不能擅自复活 |
| 模型／工具故障 | 明确有据回应；后续正常交流可用，不误记完成 |
| 协作启动 | 一次准入；真实责任绑定、成员独立贡献、负责人整合，而非角色模拟文本 |
| 成果检查返工 | 缺陷定位到成果版本，原工作有界修订，不另建任务 |
| 投递失败 | 执行与送达分开，仅重投原成果，unknown 不盲发 |
| 重启／断线 | 已接纳消息和关键终局可对账；不重复执行／送达，不靠内存标志成功 |

真实渠道外发必须有明确测试目标与有效授权；未做就标 GAP。
