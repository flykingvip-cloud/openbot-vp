# C6.1 joint matrix — promotion completion binding

Status: read-only. C6.1 updates PR #1237. It does not change Track A Apply, Verification, or Recheck, and it does not open E5.2.

`promotionCompleted` reads structured ledger events. Each event carries `eventId`, `type`, `tenantScope`, `proposalId`, `experimentId`, `applicationId`, `verificationId`, `target`, `surfaceId`, `candidateRef`, `principalRef`, and `timestamp`. A `string[]` of event types is not accepted.

Completion is true only when all of these hold together:

1. Exactly one `promotion.completed` event for the current proposal.
2. That event's tenant is the current tenant.
3. It names the current Proposal, Experiment, Application, and Verification.
4. Target, surface, and candidate match.
5. The Application status is present and is not `rolled_back` or `failed`.
6. The Verification names the current Application.
7. Recheck is `RESOLVED`.
8. EvaluationPolicy action is `promote`.
9. `authorityOk` is true.
10. `guardrailDegraded` is false.

If any item fails, `promotionCompleted` stays false and the visible copy does not contain 已完成进化.

| Case                                                  | evaluationDecision                                | promotionCompleted | promotionEligible |
| ----------------------------------------------------- | ------------------------------------------------- | ------------------ | ----------------- |
| `REGRESSED` plus a matching promotion event           | rollback                                          | false              | false             |
| `STILL_OPEN` plus a matching promotion event          | hold                                              | false              | false             |
| Binding mismatch plus a promotion event               | block                                             | false              | false             |
| `promotion.completed` for another proposal            | unchanged promote when this closure is `RESOLVED` | false              | true              |
| Application `rolled_back` plus a promotion event      | policy result                                     | false              | false             |
| Verification bound to another application             | policy result                                     | false              | false             |
| Target, candidate, or tenant on the closure disagrees | block                                             | false              | false             |
| Promotion event tenant disagrees                      | promote when the closure itself matches           | false              | true              |
| Two or conflicting promotion events for this proposal | block / `promotion_event_conflict`                | false              | false             |
| Recheck missing                                       | block / `recheck_required`                        | false              | false             |
| `RESOLVED` and every binding matches                  | promote                                           | true               | true              |

Shadow flags stay `executedConsumer=false`, `directMutatorsRetired=false`, `e52SwitchAllowed=false`, and `singleTrack=false`.

C6.1 is not E5.2.
