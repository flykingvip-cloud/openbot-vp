# Evaluation Surface Matrix (E0.2)

Authority of record for evolution semantics: `packages/evolution-core`.

Default autonomy: **assist**. Every registered surface has `autoApply=false`.

Negative facts (`guardrailDegraded`, experiment `regressed`, external `contradicted`, recheck `REGRESSED`) always rollback. Sample, confidence, or rollback-drill gaps must not downgrade those to observe. A missing rollback drill only blocks Promote.
