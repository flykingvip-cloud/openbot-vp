# CogniWeave Docs

This directory is the canonical documentation home for the CogniWeave SDK package.

It should contain the product and engineering documents required to evolve CogniWeave as an independent product inside this repository, including:

- PRD documents
- technical specifications
- architecture decisions
- implementation plans
- evaluation notes
- product positioning and integration guides

Current package posture:

- publishable npm package boundary
- release artifacts validated by build + install smoke gates
- no registry publish performed as part of routine repo changes
