# 独立工作工序（A 授权 → B 本机 → C 串联）

本文件是可执行步骤。原则见 `SKILL.md`。扫码循环仍以 `browser-scan-proxy` 为准，这里不重写。

OpenBot 没有 `request_user_form` / `request_box_help`。账密填写走隔离浏览器或 `op` 注入，不要假装有写后即焚聊天表单。

## A. 授权（连接器 → CLI/网页 → 人出场）

### A1. 先找已有工具

对任务碰到的**每一个**服务问：有没有官方 CLI、Gateway RPC、已装技能、已认证 MCP。有 → 用它。连接器只是缺登录时，走它自己的认证，**不要**改用未登录的隔离浏览器绕过。

用户已经在下任务（「去拉订单」「去改控制台」）。不要再问「要不要我用浏览器」。这句只取消执行面询问，不取消高风险确认：对外发送、广播、外部写入、删除、发布、改权限、写凭证、重置密钥、不可逆覆盖，仍然先确认再执行。只把人必须出场的那一步亮出来。

### A2. 启动登录

- 网站：打开**直达** URL。用户贴了链接、或能拼出带 query 的搜索/设备码页，就直接 `open`，不要从首页点进去重拼。
- CLI（`gh auth login --web`、同类设备码）：在 **gateway/sandbox 或已选节点** 跑官方命令，把设备码和验证链接给用户。查 `auth status` 收尾。设备码只用于当次对话。
- **不要替用户点最终 Authorize / 同意授权**，除非用户已明确要求，并且当前 snapshot 已确认就是那一页。

### A3. 凭据优先级（低打扰 → 高打扰）

1. **已有会话**：CLI 已登录、隔离 cookie 还在、节点 Connected=1 → 跳到执行。
2. **1Password CLI**：用**当前页完整 URL** 在用户自有保险库查（走 `1password` 技能，tmux 里 `op`）。匹配项注入页面或 CLI，值不回显聊天。条目自带 OTP 时，站点要码就继续由 `op` 填，不要一见验证码页就带路。无匹配：说保险库没有该项；下次重试再 `op` 刷新，不要反复空报。
3. **扫码**：页上是二维码 → `browser-scan-proxy`。
4. **可定位的打字段**：snapshot 有可用 ref/label、同域可填 → 在隔离页代填。一次只填当前步可见字段。填完由数字人点提交。单字段 OTP 填完立刻提交（码会过期）。密钥字段失败：换新 snapshot 再填，或升级到第 5 步；**禁止截图核验密码框**。
5. **人必须上手**：Passkey / WebAuthn、设备批准、图形/拼图验证码、SSO、跨域 iframe / 封闭 shadow 填不到。短指令交接（隔离页保持打开，或 Peekaboo 指窗口），不要先问「要不要你自己来」。回来先 snapshot 当前屏，再续 checkpoint。
6. **OTP 特例**：已接管的企业邮/个人邮里有码 → 自己读、自己填，不要让用户抄到聊天。

长按「我是人类」：用 `browser` `evaluate` 按下并等待，或本机窗口用 peekaboo 按住。**不要**为此走带路。图形拼图仍走第 5 步。

### A4. 登录收尾

网站：URL 已离开登录墙。CLI：`auth status` 通过。然后继续原任务，不要停下来交操作手册。

## B. 本机读写

云上 sandbox/gateway ≠ 用户电脑 ≠ SSH 生产机。动用户磁盘必须指定 **Connected=1** 的节点。

### B1. 选机器

1. `nodes` 列出已配对且在线的节点。
2. 用户消息带来源机器（或「这台 Mac」）时默认用它。
3. 多台在线且目标不清，问一次再动。
4. 未连接先恢复节点，不要改走带路。

### B2. 本机授权

`exec host=node` / `nodes.run` / Grant / TCC 弹窗是预期步骤：

- 先一句话说在哪台机器做什么
- 再发起调用
- 拒绝 → 停止并说明未写入；不要当错误刷屏
- 不要未说明用途就连续弹授权

### B3. 存到桌面（或其它本机路径）

1. 交付物先在 sandbox / 远程机构造完（少占本机授权）。
2. 在节点上解析目标目录（macOS `$HOME/Desktop`、Windows 用户 `Desktop`，以查询为准）。
3. 拷到明确文件名。
4. 核存在与大小，再把完整路径告诉用户。

反向（本机 → 远端）同样要授权。批量结构化数据：先生成文件再上传，不要在网页里逐格打字。

### B4. 本机命令

只在确实需要本机环境时执行（路径、已装软件、本机项目）。打包、转换、生成能在远端做完的，不要占用本机。

## C. 一次任务的推荐顺序

1. 一句话目标 + 私有清单（`goal` / `host` / `loginUrl` / `forbidden` / `checkpoint` / `deliverable`）
2. 走 **A** 完成授权
3. 在远端/隔离浏览器做完写入并独立验收
4. 需要落盘时走 **B**
5. 用证据 + 本机路径回复

中途授权过期：只续 `checkpoint.next`，禁止重复提交已成功的表单。
