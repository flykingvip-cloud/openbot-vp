# ASR 路由：一个音频一个供应商

`openai-whisper`（本地 CLI）与 `openai-whisper-api` 二选一。禁止对同一文件各跑一遍再「选更好的」。

## 选路

| 用户要的产物          | 走哪条                                                       | 不要                                 |
| --------------------- | ------------------------------------------------------------ | ------------------------------------ |
| 只要正文 / 纪要       | 本地 `whisper … --output_format txt`（无 CLI 再 API 出 txt） | 为了保险再打一遍云端                 |
| 要时间轴 / SRT / 字幕 | 本地 `whisper … --output_format srt`                         | 先出 txt 再换 API 要时间轴（算改投） |
| 已有转写定本          | 直接用该文件                                                 | 换模型重跑                           |

`qiaomu-cut` 若只需口播稿，先找工作区已有 `.txt` / `.srt`。没有才按上表新开一次。

## 改投禁令

同一输入文件（路径 + mtime 或 checksum）一旦选定供应商并开始跑：

- 失败：向人报失败原因，等明确指令才许换家
- 成功：结果就是定本；「再准确一点」也要用户点头才重跑
- 禁止并行提交本地 + API

建议在输出旁写一行 `asr-job.txt`：`provider=openai-whisper|openai-whisper-api`、输入路径、输出路径。下一轮先读这个文件。
