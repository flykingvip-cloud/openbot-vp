# 公众号控制台地图

先读当前页，再改。微信会改版，锚文案比固定 URL 更可靠。

## 入口

| 页           | URL                                                                                   | 成功文案                               |
| ------------ | ------------------------------------------------------------------------------------- | -------------------------------------- |
| 公众平台登录 | `https://mp.weixin.qq.com/`                                                           | 「设置与开发」「功能」「草稿箱」       |
| 旧基本配置   | 登录后左侧「设置与开发」→ 顶栏「基本配置」                                            | 「开发者ID」「开发者密码」「IP白名单」 |
| 新开发者平台 | `https://developers.weixin.qq.com/console/product/mp/<appId>?tab1=basicInfo&tab2=dev` | 「开发信息」「IP 白名单」              |

遇到「前往微信开发者平台 / 能力已迁移」：点进去。这是扫码 ②，常要再登录 / 授权，不要当成已经进了开发信息。

**旧页陷阱（2026-09-19 实操）：** `mp.weixin.qq.com`「账号开发信息」仍能改 IP，弹窗名单可能只显示一部分（当时只见 `8.217.93.71`，开发者平台才是 `8.217.93.71, 117.129.37.33`）。在旧弹窗点「确认修改」会覆盖掉新平台已写入的 IP。旧页「服务器配置 → 令牌 (Token)」是消息推送字段，**不是** OpenBot 凭证，不要填、不要启用。IP / AppSecret 以开发者平台为准。

## 必抄字段（可写进报告）

- 公众号昵称
- 主体名称
- AppID（`wx` + 16 位）
- 当前 IP 白名单列表（回读，不要凭记忆）

## 禁止抄进聊天 / 仓库

- AppSecret
- 页面上的 access_token / 任意 token
- cookie、登录二维码截图入库

## IP 白名单（无公开写入 API）

OpenBot 只能抄工作台出口 IP，**不能**自动读取或改写微信侧白名单。名单仍缺这些 IP 时，保存就是扫码 ④（若没重置密钥则是第 3 张）。

1. 优先新页：开发信息 → IP 白名单 → 修改。旧页「基本配置 → IP白名单」常已迁走。
2. 把 OpenBot 工作台「出口 IP」**全部**填入，英文逗号或页面允许的分隔。
3. 保存弹出**管理员微信扫码确认**。这不是登录失败，不要重开 `mp.weixin.qq.com`。
4. 确认后立刻回读列表。缺一个出口 IP 就会 `40164`。

双出口是常态：工作台可能先只展示一个 IP，网关实际还有第二个。清单以**当前**工作台展示为准，并与最近一次 `40164` 报文里的 IP 合并。

## AppSecret

- 身份店已有密钥且换票通过：不要重置。
- 需要新密钥：点「重置」或「查看」→ 管理员确认（扫码 ③）→ 新密钥只显示一次 → 立刻写入身份店并清缓存票。
- 打开页时若重置弹窗已经在：不要关掉。按用户授权完成扫码 ③，或明确取消。

## 只读验收（可选）

换票成功后可拉账号资料核对昵称 / 主体：

`GET https://api.weixin.qq.com/cgi-bin/account/getaccountbasicinfo?access_token=...`

不要把 access_token 打进聊天。不要发图文、不要调 `freepublish`。

## 禁止操作

群发、发布已上线图文、删除素材、改账号主体、改登录邮箱、解绑管理员、把隔离会话的 cookie 存进仓库。
