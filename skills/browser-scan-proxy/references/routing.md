# 意图分流

本文件只做分流。执行细节以 `SKILL.md` 为准。

## 用本技能

| 用户说                                         | 是否触发                           |
| ---------------------------------------------- | ---------------------------------- |
| 扫码登录 / 你打开网页我来扫 / 我来扫码         | 是                                 |
| 重新启动浏览器 / 再开一扇扫码页                | 是（走 RESTART_SCAN）              |
| 已经扫码完毕 / 我扫过了                        | 是（先看当前标签，不要重开登录页） |
| 授权过期 / 二次扫码 / 会话失效再登             | 是（checkpoint 后重扫）            |
| 没有 AccessKey，但要改阿里云 / 云控制台 / 后台 | 是                                 |
| 你自行获得你需要的东西（已声明用户只扫码）     | 是                                 |

## 不用本技能

| 用户说                                            | 交给                                                  |
| ------------------------------------------------- | ----------------------------------------------------- |
| 页上是账号密码 / OTP，不是二维码                  | `independent-work` A3（隔离代填 / `op` / 已接管邮箱） |
| 找不到按钮、带我点、怎么配                        | `user-guidance-protocol`                              |
| 读这个公开网页 / 调研 / 提取正文                  | `web-research` / `web_fetch` / `defuddle`             |
| 个人微信扫码绑定数字人                            | `wechat-personal-catalog` → ops                       |
| 公众号 AppID / AppSecret / IP 白名单 / 开发者平台 | `wechat-official-credential`（本技能只提供扫码循环）  |
| 个人邮箱网页拿授权码                              | `personal-mail-assistant` + 带路 YAML                 |
| 只要 CLI / AccessKey / 粘贴记录值                 | 直接改，不必开浏览器                                  |

## 与 browser 工具的关系

`browser` 是工具，不是技能。禁止再做一个叫 `browser` 的平行技能。本技能只编排「人扫码 + 隔离会话代操作」这一条工序。

跨服务器 + 本机节点 + 浏览器的整条任务，先交给 `independent-work` 选执行面；一旦判定要扫码登录，扫码循环仍以本文件为准。
