# 微信公众号运营策划

用户要的是**详细运营策划**，不是发一篇稿。读完本文件就按下面交付，需要更长的渠道方法论再读同目录 `AGENTS.md`。

## 先分流

| 用户其实要                        | 立刻改走                     |
| --------------------------------- | ---------------------------- |
| 排版 / HTML / 封面 / 发草稿箱     | `wechat-article`             |
| AppID / AppSecret / IP 白名单     | `wechat-official-credential` |
| 同一事实源拆到小红书 / X / 短视频 | `content-ops`                |

只有「涨粉、留存、转化、菜单、内容支柱、发文节奏」留在本技能。

## 这一轮交付

用中文写，能落地、能验收，不要空 KPI：

1. **目标**：增长 / 留存 / 转化，选一个主目标，写清 4 周成功标准。
2. **订阅者人设**：谁、痛点、为什么关注、不看什么。
3. **内容支柱**：3–5 条，每条给示例选题，不编造已发生的数据。
4. **四周日历**：每周 2–3 条，标注格式（图文 / 菜单 / 自动回复）。
5. **菜单与自动回复**：主菜单、关键词、欢迎语；只出结构，不改公众号后台。
6. **下一轮实验**：最多 3 个，每个有假设、动作、7 天看什么指标。

缺账号现状或数据时，标明假设，不要假装有后台数字。

## 不要做

- 不装配主题 HTML，不调用发布脚本，不写草稿箱，不代扫码改白名单
- 不把本技能 key 答成 `wechat-oa-marketing` / `wechat-oa-ops` 或其他自造名
