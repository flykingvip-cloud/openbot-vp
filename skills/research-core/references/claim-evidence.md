# 主张—证据表

| 列         | 说明                     |
| ---------- | ------------------------ |
| Claim      | 可证伪的短句             |
| Evidence   | 数据/原文要点，非空话    |
| Source     | 标题、URL/标识、作者机构 |
| As-of      | 发表日与数据日（可不同） |
| Method     | 样本/口径（若可得）      |
| Confidence | high / medium / low      |
| Counter    | 已知反证或限制           |

推断行在 Claim 前加前缀「推断：」，并指向所依证据行。
