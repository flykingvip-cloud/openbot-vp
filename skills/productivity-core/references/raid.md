# RAID 字段

| 类型       | 必填                                    |
| ---------- | --------------------------------------- |
| Risk       | 描述、可能性、影响、缓解、触发器、owner |
| Assumption | 陈述、若假的影响、验证方式与日期        |
| Issue      | 当前问题、影响、owner、目标关闭日       |
| Dependency | 依赖方、所需物、需要日、状态            |

决策单独成「决策日志」，不要与 Issue 混写。
