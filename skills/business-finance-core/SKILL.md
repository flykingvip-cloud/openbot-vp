# business-finance-core（经营与财经办公）

把预算假设、管线证据与产品信号收成可决策的经营材料。实际 / 预测 / 情景分列；合计可勾稽；建议写清敏感性与风险。

## 概述

- **预算规划**：假设 → 收入/成本/现金/时点/owner；基准/乐观/悲观。
- **销售管线**：阶段定义、下一步、关单日、证据、集中度与预测风险。
- **产品反馈**：按用户段落、需求、频次、严重度、业务价值与证据强度归类。
- 表格模型 → spreadsheets；分析路由可协作 data-analysis-core；战略取舍 → strategy-core。

## 前置

1. 确认决策者、期间（月/季/年）、币种、口径（含税否、确认收入规则）。
2. 盘点输入：总账摘要、CRM 导出、反馈原声、既有预算版。
3. 标明实际 vs 预测字段；禁止混写在同一无标签列。
4. 外部写入（CRM/ERP）默认需用户授权；本技能先出工作区文件。

## 流程

### A. 预算规划

1. 列驱动假设（量、价、转化、成本率、季节性）；每条可调。
2. 建基准情景；再做上下行；输出对关键假设的敏感性。
3. 标注 owner 与检视节奏；现金时点与费用确认时点分开。
4. 勾稽：分部合计 = 总计；情景差额可解释。

### B. 销售管线复盘

1. 核对阶段定义与退出标准；僵尸机会（无下一步/过期关单日）单列。
2. 每单检查：证据强度、下一步、关单日可信度、金额异常。
3. 集中度：头部客户/代表占比；单一依赖风险。
4. 预测：权重法或管理层覆盖；写清乐观偏差来源。

### C. 产品反馈分析

1. 标签：段落、需求主题、频次、严重度、商业价值、证据强度。
2. 区分原声与解读；高频低价值 vs 低频高严重度分别呈现。
3. 输出主题优先级与建议验证实验（非直接拍板路线图时可停在含义）。

## 输出

```text
output/business-finance/<id>/
  budget-model.xlsx
  assumptions.md
  pipeline-review.md      # 或 .xlsx
  forecast-risk.md
  feedback-themes.md
  exec-brief.md
```

经营简报顺序：本期结论 → 相对预算/预测差异 → 风险与集中度 → 建议动作（含敏感性）。

## 边界

- **做**：预算情景、管线健康、预测风险、反馈主题、经营简报。
- **不做**：编造流水或关单概率；未授权写回 CRM/财务系统；冒充持牌财务建议。
- **相邻**：深度投研证据 → finance-research / research-core；表工艺 → spreadsheets；数据分析路由 → data-analysis-core。
- **警告：** 勿使用 Codex artifact / `openai.yaml`；交付用工作区文件。勿在正文存密钥。

## 触发样例

- 「根据这些假设做一版季度预算和上下行情景」
- 「管线复盘：哪些是僵尸单，预测风险在哪」
- 「把客户反馈归主题并按业务价值排序」
- 「经营简报：实际 vs 预算，敏感性写清楚」
