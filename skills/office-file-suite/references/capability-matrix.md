# 能力矩阵

运行时以 `office_file` 的 `capability` 动作为准。下表是文件引擎的设计状态。

| 项目                       | 状态     | 说明                                             |
| -------------------------- | -------- | ------------------------------------------------ |
| Word 创建与局部编辑        | 已验证   | OOXML，保留未改段落和表格                        |
| Word 修订与批注            | 已验证   | tracked change 与 comments                       |
| Word 版式预览              | 有限支持 | 始终有 HTML 和分页估计；像素预览需要 LibreOffice |
| PPT 创建与非目标页保留     | 已验证   | 只改目标 slide XML                               |
| PPT 图片与图表             | 已验证   | PNG 与 chart part                                |
| PPT 像素预览               | 有限支持 | 有 LibreOffice 时为已验证                        |
| 表格、CSV、数字格式、图表  | 已验证   |                                                  |
| 公式重算                   | 有限支持 | 有界函数集，不是完整 Excel                       |
| PDF 中文、抽取、表单、分页 | 已验证   | 需要系统 CJK 字体；缺字体时字形可能缺失          |
| 个人 / 租户 / 平台模板     | 已验证   | 写租户模板要企业管理员，写平台模板要平台管理员   |
| 租户与个人隔离             | 已验证   | 下载、预览、编辑都校验所有者                     |
| Excel 实时会话             | 未接入   | 没有桌面 Excel 连接器                            |
| Google Workspace           | 未接入   | 没有 Drive / Docs / Sheets 连接器                |
