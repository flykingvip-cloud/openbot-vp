# 行动项字段约定

| 字段     | 要求                                   |
| -------- | -------------------------------------- |
| ID       | 稳定短码，如 A1、A2                    |
| 行动     | 可验证的祈使句结果，非「继续跟进」空话 |
| 负责人   | 单主责；多人协作写主责 + 协作          |
| 截止日期 | ISO 日期或「未定期」                   |
| 状态     | open / blocked / done / cancelled      |
| 验收     | 完成时可见证据                         |
| 依赖     | 阻塞本项的 ID 或外部事件               |
| 来源摘录 | 原文短引，防误写承诺                   |

状态迁移：缺负责人或日期不得标 done。blocked 必须写阻塞原因。
