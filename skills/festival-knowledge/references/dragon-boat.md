# 端午节 (Dragon Boat Festival)

> Lunar 五月初五 · National holiday in China

## 🌿 第一层 · 远古源头

端午节的历史比屈原早一千年以上。它的远古层由三股源流交汇而成：

### 百越龙图腾祭

- 长江中下游的古越族以龙为图腾，每年农历五月五日举行龙祭
- **赛龙舟的原始形态**：模拟龙形、祭祀龙神——闻一多先生《端午考》有专门论证
- 古越人的断发文身习俗也与龙图腾崇拜有关

### 夏至节点驱疫

- 农历五月在古代历法中被视为「毒月」「恶月」
- 仲夏时节蛇虫出没、瘟疫高发，所以端午习俗的核心功能是**驱邪避瘟**
- 挂艾草、饮雄黄酒、沐兰汤——这些习俗比屈原早得多

### 天文学视角

- 端午日，苍龙七宿正悬南中天，即《易经》「飞龙在天」之象
- 星象上的龙与民俗中的龙在五月初五这一天交汇
- 端午本质上也是**仰观天象、顺应时令**的节日

## 📜 第二层 · 历史附会

随着时间推移，不同地区将各自的历史人物「嵌套」进这个古老节日：

| 人物       | 时期    | 关联地区     | 叙事                                                                                                                                                      |
| ---------- | ------- | ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **屈原**   | 战国·楚 | 全国（主流） | 楚国大夫，主张联齐抗秦遭排挤流放。公元前278年秦破郢都，屈原于五月初五抱石投**汨罗江**殉国。百姓划船搜救（→赛龙舟），投粽喂鱼防其啃食屈原遗体（→吃粽子）。 |
| **伍子胥** | 春秋·吴 | 江浙一带     | 吴国忠臣助夫差称霸，后被赐死，尸首被投入江中，传说忌日与端午相近。                                                                                        |
| **曹娥**   | 东汉    | 浙江上虞     | 14岁孝女投江寻父，五日后抱父尸出，被奉为孝道典范。                                                                                                        |
| **介子推** | 春秋·晋 | 山西部分     | 寒食节传说偶有混同至端午习俗中。                                                                                                                          |

**屈原版之所以成为主流**：提供了「忠君爱国」的悲剧美学叙事，历朝历代官方推崇这一价值观，加上《离骚》《九歌》等文学经典的加持，屈原与端午的绑定至唐宋已不可分割。

## 🏮 第三层 · 民俗传承

### 核心习俗

| 习俗                  | 内涵                               | 起源关联                 |
| --------------------- | ---------------------------------- | ------------------------ |
| 🚣 **赛龙舟**         | 龙形船竞渡，模拟打捞屈原           | 百越图腾祭 + 屈原叙事    |
| 🍙 **吃粽子（角黍）** | 竹叶/箬叶包裹糯米                  | 投食喂鱼演变；晋代已普及 |
| 🌿 **挂艾草 & 菖蒲**  | 插于门楣驱邪避毒                   | 恶月驱疫习俗             |
| 🧧 **佩香囊**         | 内装香料草药，提神驱虫             | 同上                     |
| 🍶 **饮雄黄酒**       | 驱虫解毒（现代已不提倡，雄黄有毒） | 恶月驱疫习俗             |
| 🛁 **沐兰汤**         | 用草药煮水沐浴                     | 先秦已有记载             |

### 冷知识

- 粽子最早叫「角黍」，东汉《说文解字》已有记载
- 2009年，中国端午节被列入联合国人类非物质文化遗产代表作名录
- 甜粽（豆沙、枣泥）vs 咸粽（蛋黄、鲜肉）之争，本质上是南北饮食文化差异

### 祝福讲究

端午祝福应当说 **「端午安康」** ，而非「端午快乐」。底色是纪念与驱邪，安康才是核心祝愿。
