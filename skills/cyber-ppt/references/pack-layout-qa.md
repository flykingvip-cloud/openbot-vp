# Pack layout / QA notes（并入 cyber-ppt）

来源概念：presentations pack 的 style / finalization / writing-quality。已去掉 Codex artifact_tool、container_tools 与专有 citation。

## 文案

- 直接、具体；避免空口号、堆砌三连、生硬被动、AI 腔标点（滥用分号/竖线/箭头装饰）。
- 标题优先点名对象；设置页用名词短语，发现页才用 takeaway 句。
- 去掉短标题尾部句号；正文正常标点。

## 版式

- 用户模板/品牌优先于默认。
- 可读字号：无模板时经验下限约标题 32pt+、页标题 22pt+、正文 9.5pt+（仍服从 CyberPPT Typography Scale）。
- 封面保持低密度；内容页结论先行 + 证据 + SO WHAT。
- 默认扁平构图；非用户要求勿做成 UI 卡片墙/仪表盘组件风。
- 表与数据图保持可编辑原生对象；装饰视觉另议。

## 终检（与 quality-assurance 互补）

1. 渲每一页；整页阅读尺寸检查，联系表只作全局流。
2. 修意外重叠、裁切、换行、页脚不一致、图数不符。
3. 事实可追溯；不编造。
4. 结构校验通过 ≠ 视觉合格；仍要 blueprint vs render 对照（见主 QA）。
5. 交付工作区 PPTX；不交私有 builder / staging 除非用户要。
