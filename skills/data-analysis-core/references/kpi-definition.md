# KPI 口径卡

| 字段      | 说明             |
| --------- | ---------------- |
| 名称      | 业务可读名       |
| 定义      | 一句话 + 公式    |
| 分子/分母 | 明确筛选         |
| Grain     | 日/周/客户/订单… |
| 基线      | 预算/同期/滚动   |
| 单位      | 币种、%、人数    |
| 所有者    | 指标 owner       |
| 已知限制  | 延迟、样本偏差   |

未填定义与 grain 前，不做「结论性」解读。
