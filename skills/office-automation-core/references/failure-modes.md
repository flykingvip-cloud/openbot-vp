# 常见失败与处理

| 模式     | 处理                                       |
| -------- | ------------------------------------------ |
| 缺数     | 显式占位 + 告警；禁止静默填 0 冒充         |
| 重复行   | 按主键去重；冲突行进 quarantine            |
| 陈旧输入 | 比对水位/修改时间；超 SLA 则跳过或降级输出 |
| 部分失败 | 已成功步骤可续跑；X 步骤失败不自动重试外发 |
| 权限不足 | 停在审批前，列所需授权                     |

重试默认有上限与退避；超过上限写 runbook 升级给人。
