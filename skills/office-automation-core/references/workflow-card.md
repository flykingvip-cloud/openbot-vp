# 流程卡字段

| 字段     | 说明                   |
| -------- | ---------------------- |
| 触发     | 时间 / 事件 / 手动     |
| 输入     | 路径或连接器 + 新鲜度  |
| 变换     | 有序列表，标注 R/W/X   |
| 输出     | 工作区路径与命名       |
| 接收人   | 人/群/渠道；默认先草稿 |
| 频率     | cron 语义或「手动」    |
| 负责人   | 流程 owner             |
| 停止条件 | 何时停、何时降级       |
| 审批点   | 每个 X 步骤前的门      |
| 幂等     | 重跑是否安全           |

R=只读，W=写工作区，X=外部副作用。
