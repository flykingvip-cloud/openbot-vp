# PPTX Skill — Reference Templates

> Pre-built slide structure templates for common consulting / business scenarios

---

## 1. Strategy Report (麦肯锡标准)

```
1. Cover          — 战略规划报告 | 标题 / 副标题 / 部门
2. Agenda         — 目录：市场分析 / 竞争格局 / 战略选择 / 行动计划
3. Exec Summary   — 执行摘要 (3 key points)
4. Section        — 01 市场分析
5. Text           — 宏观市场趋势 (正文 + 数据来源)
6. Chart Bar      — 季度趋势柱状图
7. Table          — 竞品对比表格
8. Section        — 02 竞争格局
9. Matrix         — 2x2 战略定位矩阵
10. Two Column    — SWOT分析
11. Section       — 03 战略选择
12. Waterfall     — 目标推导过程
13. Takeaway      — 关键结论 (3点)
14. Next Step     — 行动计划 (时间线)
15. Appendix      — 附录参考资料
```

## 2. Monthly Review (月度回顾)

```
1. Cover          — [月份] 月度业务回顾
2. Agenda         — 本月重点 / KPI达成 / 下月计划
3. Bullet         — 本月Top 5成绩
4. Chart Bar      — KPI达成率
5. Table          — 项目进度跟踪表
6. Takeaway       — 问题与挑战
7. Next Step      — 下月重点行动计划
```

---

## 3. Product Launch (产品发布)

```
1. Cover          — 产品名称 | tagline | 日期
2. Agenda         — 议程
3. Exec Summary   — 一句话价值主张 + 3大亮点
4. Section        — 01 产品概述
5. Text           — 产品定位与目标用户
6. Two Column     — 核心功能 vs 竞品差异
7. Section        — 02 商业模式
8. Chart Bar      — 市场规模与预测
9. Table          — 定价方案对比
10. Quote         — 用户证言 / 早期用户引言
11. Takeaway      — 关键结论
12. Next Step     — 上市计划时间线
```

```
1. Cover          — 项目名称 | 提案方 | 日期

8. Two Column     — 方案A vs 方案B
9. Matrix         — 方案选择矩阵
10. Waterfall     — 预期收益推导
11. Table         — 实施路线图
12. Takeaway      — 为什么选择我们
13. Next Step     — 下一步行动
```

## Slide Type Selection Guide

| If you need...       | Use this type                |
| -------------------- | ---------------------------- |
| State a conclusion   | `exec_summary` or `takeaway` |
| Show data over time  | `chart_bar`                  |
| Compare options      | `two_column` or `matrix`     |
| Show a process/steps | `waterfall` or `next_step`   |
| List items           | `bullet` or `agenda`         |
| Give details         | `text` or `table`            |
| Emphasize a quote    | `quote`                      |
| Divide chapters      | `section`                    |
