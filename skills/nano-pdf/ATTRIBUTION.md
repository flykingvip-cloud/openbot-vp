# ATTRIBUTION

## Origin

OpenBot `nano-pdf` keeps existing OpenClaw/OpenBot CLI skill metadata and
absorbs create/render/verify and AcroForm guidance inspired by Codex-oriented
PDF skill packs. Prose and delivery rules are rewritten for OpenBot terminal
enterprise users (workspace files, not Codex artifacts).
