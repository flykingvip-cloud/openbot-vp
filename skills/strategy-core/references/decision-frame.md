# 决策框

| 字段     | 说明                     |
| -------- | ------------------------ |
| 决策问题 | 一句可裁决的问题         |
| 决策者   | 谁拍板                   |
| 时界     | 决策与生效时间           |
| 成功标准 | 可检验                   |
| 约束     | 预算、合规、能力、政治   |
| 假设     | 编号列表；标明若假的影响 |
| 非目标   | 本次明确不做             |

未填决策者与成功标准前，不要急着给「最终建议」。
