# Repurpose

输入：一份 Source of Truth（研究、长文、纪要）。输出：多平台表达 + 回溯表。

## 平台只改形式

| 形态       | 形式约束   | 不得改                   |
| ---------- | ---------- | ------------------------ |
| 公众号要点 | 节选+过渡  | 数字、因果               |
| 小红书     | 短句、条目 | 同上                     |
| X Thread   | 一条一信息 | 同上                     |
| LinkedIn   | 职业语境   | 同上                     |
| 短视频脚本 | 口播时长   | 同上                     |
| 3:4 图组   | 一页一信息 | 同上；见 `known-link.md` |
| 知识卡片   | 单主张     | 同上                     |
| PPT 大纲   | 一页一断言 | 同上                     |

## 回溯表

`衍生文件:行 → 源文件:锚点 → 事实原文`

`source_trace.py` 抽数字、大写专名、ISO 日期做硬匹配。匹配失败先修衍生。

禁止整篇改写外部爆款当「运营」。
