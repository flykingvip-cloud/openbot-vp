# 内容运营

先确认 Source of Truth，再衍生。没有源材料就只出选题假设，并标明「待核事实」。

## 先判断

1. 已有报告/长文/视频文稿，还是要从热点找题？
2. 目标平台与必须保留的硬事实？
3. 用户要的是选题、素材、多版本，还是排期？

## 能力

| 能力      | 做什么                                                                                  |
| --------- | --------------------------------------------------------------------------------------- |
| trend     | 扫近期话题，保留平台、URL、时间、指标，不合成伪总分                                     |
| topic     | 从趋势或库存内容出选题角度与标题，标题不编造结果                                        |
| source    | 建源索引：事实、引语、数字、资产路径。下载只接受已知链接，见 `references/known-link.md` |
| repurpose | 一源多表达，见 `references/repurpose.md`；图组/3:4 见 `references/known-link.md`        |
| planning  | 日历与复用节奏，见 `references/planning.md`                                             |

未指定时，有长文 → repurpose；只有「最近火什么」→ trend + topic。热点结果不是素材：未确认 URL 不得下载。

## REPURPOSE

同一源可转为：公众号要点、小红书、X Thread、LinkedIn、短视频脚本、知识卡片、PPT 大纲。

每条衍生必须能回溯到源段落。跑：

```bash
python3 {baseDir}/scripts/source_trace.py --source <源文件> --derived <衍生文件>
```

数字、专名、日期对不上就改衍生，不改源。

## 默认输出

```text
Source of Truth 索引
平台版本（各一）
回溯表（衍生句 → 源锚点）
未验证 / 故意省略
可选：7 日内容计划
```

标题默认 5–8 个，不要为凑数造 30 条。不要整篇复制外部爆款。

## 禁区

- 为平台传播改写事实或因果
- 把深度研究或终稿写作做完（交接）
- 内置视频下载、飞书同步、生图流水线
- 把监控 Cookie / API Key 写入技能或产出

## 交接

| 需求             | 去向                                               |
| ---------------- | -------------------------------------------------- |
| 题目还没研究清楚 | `deep-research`                                    |
| 源材料还没读懂   | `knowledge`                                        |
| 要一篇完整终稿   | `content`                                          |
| 封面/页面视觉    | `design` 或已有生图技能                            |
| 公众号排版成稿   | `wechat-article`                                   |
| 公众号草稿箱     | `wechat-article` 排版后走身份工具（draft-handoff） |

## 组合

源材料来自 `deep-research` / `knowledge` / `content`。需要完整新长文时回 `content`，不要在 ops 里重写研究。

## 验收

- 每条衍生能指回源锚点
- `source_trace.py` 对硬事实通过，或列出缺失
- 平台版本之间事实一致
- 无源材料的热点标「待核」

## 触发样例

- 「把这份 5000 字研究拆成公众号 + 线程 + 口播」
- 「这周 AI Agent 有哪些可做选题，先不要写正文」
- 「给三条硬事实做一周复用计划」
