### My robots

This account listed manageable robots, each with `进入工作区`. There was no `新建` button.

Opened `大白管家`. Tabs on screen: `身份`, `能力`, `成长`, `运营授权`, `协作`, `数据`. No `危险` tab.

- `身份`: `名称`, `定位`, `角色`, `人格`, `模型`
- `能力`: `已安装` / `探索能力`
- `成长`: capability, performance, and suggestion percents; `输出格式`, `汇报节奏`, `决策方式`
- `运营授权`: enterprise and personal identities, `添加身份`
- `协作` can say `尚未参与协作小组。`
- `数据`: memory, long-term memory, knowledge base, workspace

`进入工作区` returns to the daily overview chat. It does not open a second workbench.
