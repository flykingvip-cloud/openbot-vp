# ATTRIBUTION

## Origin

This OpenBot `openbot-docs` skill is inspired by the **docs-first / one-primary-route**
workflow pattern of the Codex `openai-docs` skill (search official docs before
answering from memory; choose at most one specialized reference). The skill text,
OpenBot topic map, and references here were **rewritten for OpenBot** and are
not a verbatim copy of proprietary Codex or OpenAI documentation.

## No affiliation

This package is not affiliated with, endorsed by, or sponsored by OpenAI.
Do not present it as an official OpenAI or Codex plugin.

## Sources of truth for OpenBot facts

Prefer the OpenBot product/repo docs tree (for example `docs/start/`,
`docs/gateway/`, `docs/tools/skills.md`, `docs/channels/`, `docs/help/`,
`docs/web/`, and `docs/zh-CN/`). Paraphrase short facts; do not dump large
verbatim proprietary third-party manuals into answers or into this skill.

## Intentionally omitted

- Codex/OpenAI proprietary manuals, model guides, and helper scripts
- Branding SVG / `openai.yaml` / Codex plugin manifests from upstream packs
- Grok Bot–only UI paths presented as OpenAI product docs

## Redistribution

Before redistributing any file copied or substantially derived from a third-party
package, confirm necessary rights under that package license. When in doubt, keep
only the rewritten OpenBot documents in this tree.
