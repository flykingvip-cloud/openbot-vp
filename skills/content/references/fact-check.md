# Fact Check

对正文中的数字、日期、专名、引语、因果、排名逐条：

| 声明 | 类型           | 来源               | 状态                     |
| ---- | -------------- | ------------------ | ------------------------ |
| …    | 事实/观点/推测 | URL 或「用户提供」 | 已核 / 无法验证 / 已删除 |

## 规则

- 找不到来源：标无法验证，或删，或改成推测并明示
- 来源互斥：并列，不选顺的那条
- 禁止用「业内普遍认为」冒充已核事实
- 用户口述未证实：标「用户陈述」

不为了段落通顺补一个「大概的」百分比。
