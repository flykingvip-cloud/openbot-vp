# Pricing 三端职责边界（2026-07-19）

统一展示源：`PricingCatalogViewModel`（gateway `pricing-view-model`）+ UI `pricing-v3/*`。

| 端         | 入口                                                                 | 职责                                                                                                                                                                              |
| ---------- | -------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **平台端** | `ui/src/ui/ports/platform/pricing/page.ts`                           | 套餐配置、草稿版本、发布、差异审核、模型与计量绑定；**只读效果预览**须复用 `pricing-v3` 与同 viewport，禁止维护第二套管理端卡片。首页以「编辑工作区」为主、「效果预览」为辅 Tab。 |
| **企业端** | `cost-budget-v2` → `panels/plan/catalog-panel.ts` + my-plan / orders | 当前套餐、可升级套餐、下单支付、账单预算、席位与发票。加载失败须稳定错误态 + 重新加载，不得无退避重试。                                                                           |
| **网页端** | `pricing-v3/public-pricing-surface.ts`                               | 公开价格、价值说明、完整能力对比、试用 / 登录 / 联系销售。                                                                                                                        |

**禁止**：各端各自维护套餐名、权益枚举翻译或平行 ViewModel。  
**产品词典（展示）**：AI 员工数 · 团队席位 · AI 授权 · 月度 Credits · 并发数 · 治理/SLA 摘要。  
**计费规则**：仅 FAQ / 帮助文案，不塞进套餐卡。
