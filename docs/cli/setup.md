# `openbot setup`

Initialize `~/.gmood2008/openbot.json` and the agent workspace.

Related:

- Getting started: [Getting started](/start/getting-started)
- Wizard: [Onboarding](/start/onboarding)

## Examples

```bash
openbot setup
openbot setup --workspace ~/.openbot/workspace
```

To run the wizard via setup:

```bash
openbot setup --wizard
```
