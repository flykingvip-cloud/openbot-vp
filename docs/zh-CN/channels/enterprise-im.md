# 企业 IM 接入

企业租户在以下入口配置 **企业微信 / 飞书 / 钉钉**：

**企业控制台 → 系统设置 → 消息通道**

该页使用精简表单：先选连接模式，只填该模式必填项，再用真实对话验收。

## 设计原则

| 原则       | 在 OpenBot 中的含义                                                     |
| ---------- | ----------------------------------------------------------------------- |
| 长连接优先 | 平台支持时优先 WebSocket / Stream，无需公网 Callback                    |
| 模式互斥   | 长连接与 URL 回调凭证不同，不可混用                                     |
| 精简字段   | 写入 `channels.<id>.accounts.t_<tenant>_default.*`，不是运维全量 schema |
| 双段清单   | 先做开放平台准备，再保存 / 回填 Callback /「你好」+ 测试连通            |
| 边界       | QQ 不进入企业消息通道                                                   |

## 选择渠道

| 渠道     | 推荐模式               | 最少凭证                  | 指南                        |
| -------- | ---------------------- | ------------------------- | --------------------------- |
| 企业微信 | AIBot WebSocket 长连接 | Bot ID + Secret           | [企业微信](/channels/wecom) |
| 飞书     | WebSocket 长连接       | App ID + App Secret       | [飞书](/channels/feishu)    |
| 钉钉     | Stream 长连接          | Client ID + Client Secret | [钉钉](/channels/dingtalk)  |

已有公网网关时，仍可改用 URL 回调 / HTTP Webhook。

## 统一验收

1. 按所选模式完成开放平台检查（可见范围 / 机器人能力 / 权限 / 发布）。
2. 在 OpenBot 选择相同模式并保存凭证。
3. 仅回调模式：把只读 **Callback URL** 回填到开放平台。
4. 向机器人发送「你好」。
5. 在企业通道页点击 **测试连通**。
