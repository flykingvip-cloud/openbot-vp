**当时设想的连接方向与端点（从未实施）**

1. B′ 协议进程在 B′ 本机监听 `127.0.0.1:18790`。
2. 操作人工作站建立到 B′ 的认证 SSH，并把本机 `127.0.0.1:28791` 转到 B′ `127.0.0.1:18790`。
3. 操作人工作站建立到 A′ 的认证 SSH，并把 A′ 本机 `127.0.0.1:18791` 远程转发到本机 `127.0.0.1:28791`（即 B′ 回环）。
4. A′ 协议进程连接 `http://127.0.0.1:18791`（`OPENBOT_EXEC_PROTOCOL_B_URL`），不直连 B′ 内网或公网端口。
5. 操作人管理 A′：经同一跳板把本机 `127.0.0.1:28790` 转到 A′ `127.0.0.1:18790`。
